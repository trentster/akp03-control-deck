Using AKP03 Control

What the deck can do, and how to set it up. The last two parts are for drawing your own icons and building a set to hand to someone else. Nothing here is guesswork — these are the rules the app itself follows.

  • 1 The deck
  • 2 Menus

1The deck

Twelve controls: six keys across the glass, three buttons under them, and three dials at the side.

Choose a control, then choose what it does

Click any control on the drawing. The panel on the right answers for the one you picked: a key takes a label, an action, a picture, and a response; a dial takes one answer per part of it, so its press and each way it turns are set separately.

Nothing you do is real until you press Save to deck. Until then it is a draft you can put back with Discard changes, which appears as soon as there is something to put back.

Response: tapped, or held

Most keys fire the moment you tap them. A key can instead be held while pressed — useful for push-to-talk, or anything you want to keep down. A hold has a cut-off, so a key held down on a busy desk does not stay down for ever.

A dial's turn cannot be held: a notch has no release, so there is nothing to wait for.

Testing without saving

Test it now sends the action straight away so you can see it work before it belongs to the deck. It never saves anything.

What the deck is showing

On the deck now is what the glass holds at this moment, drawn by the deck's own renderer rather than a second copy of it — so a label that will be cut short up there looks cut short down here too.

When nobody is using it

The keys can go dark after a while with no key, button or dial touched, which is what spares the panel a fixed bright picture. Any touch wakes the deck, and it comes back exactly as it was — the same labels and pictures, a menu still open where you left it.

How long it waits is set in Settings — the small entry just above the deck's state at the bottom of the rail. Off keeps the keys lit.

If the deck goes quiet

macOS reads the deck's buttons and types the shortcuts, so the app needs two permissions: Input Monitoring and Accessibility. Both are granted to AKP03 in System Settings → Privacy & Security, then the app is quit and opened again.

Accessibility missing is announced on the page, with a strip that asks macOS for you. A newer build counts as a new app, so the two entries have to be removed and added back.

2Menus

A menu puts up to six of your own buttons on the keys, and you can always get back out of it.

Opening one

A key set to open a menu shows menu ▸ on its tile. While that menu is up, the six keys are its buttons instead of the deck's, and the drawing on the Menus page changes to show them.

Everything a menu shows is set on the Menus page, not on the Deck page.

Getting back out — always

The small left dial goes back a level, and from the top page of a menu it leaves the menu altogether. That is fixed, on purpose: it is the one control that is never given away, because a menu you cannot leave is a brick.

The big dial turns to move the highlight and presses to select. A menu that takes the big dial for something else takes it whole, so the parts the menu leaves empty simply do nothing rather than surprising you.

What a menu can take over

The three buttons under the keys, and the big dial and the right dial. Each slot left empty keeps its ordinary job, so a menu that claims nothing changes nothing.

One part of a menu is a good place for something that menu is about: turn the big dial to work the volume while you are in the menu that deals with sound.

Renaming and deleting

Both are on the menu's own page, and both are staged: a deleted menu is not gone from the deck until you press Save to deck, and Discard changes puts it back.

3One icon

The deck's keys are 60 by 60 pixels. That sounds tiny, and it is — so draw big and let it shrink. Every rule below comes from that one number.

Draw at 180×180

Design on a square canvas of 180×180. Keep the artwork inside the middle 144 pixels, leaving about 18px of margin all round so nothing is jammed against the edge of a key.

Transparent PNG

right

Save as PNG with transparency. It's what lets the black key face show through around your shape. JPEG has no transparency, so it arrives as a white square.

No SVG: icons are pictures, so raster only.

Bold shapes only

Shrink a thin line to 60 pixels and it turns to mush. Keep strokes at 8 pixels or more on the 180 canvas — that's about 3 pixels once the deck has it.

No text on the icon either — at 60 pixels a letter is a smudge. If it needs a word, it needs a different picture.

Light colours

The key face is black, and your picture is drawn exactly as you saved it — nothing is recoloured, nothing is inverted. Light art reads; dark art disappears into the face.

Name the file

The file's name becomes the icon's name in the editor. Lowercase with hyphens is easiest to read.

Anything you don't like can be renamed later, on the Icons page.

How many, how big

About 24 icons to a set keeps the list and the picker easy to scan. The app takes up to 2000, because a set imported from an icon library is a library; one you build by hand is happier small, since a set you scroll through is a set you stop using.

File size is rarely a problem: keep each picture under a few hundred KB and you'll never meet the limit. The app keeps a 180 pixel copy for its own previews and makes the 60 pixel one for the deck.

Before you upload — the one-icon checklist

  • Square canvas, 180×180
  • PNG with transparency
  • Art inside the middle 144px
  • Strokes 8px or more
  • Light colours
  • Named the way you want it read
  • Letters or numbers on the art
  • Hairlines, outlines, fine detail
  • Dark art on the black face
  • JPEG, or a photo with a background
  • Spilling past the margin
  • More than about 24 in a set

4A set

A set is a folder of icons with a small manifest that names them. Zip the folder, hand it over, and it becomes a set of its own in the sidebar — with your name on it.

The zip

One zip, one folder inside it. The folder's name is the set's id: lowercase letters, digits and hyphens, and it must match the id inside pack.json.

Yes — zip it. Loose files, or a zip with everything at the top level, will be refused.

pack.json

Three lines of facts about the set, then one entry per icon.

{
  "id": "workshop",
  "name": "Workshop",
  "author": "Your name",
  "licence": "CC BY 4.0",
  "description": "Bench icons.",
  "icons": [
    {
      "name": "find",
      "label": "Find",
      "hue": "#2f7f78"
    }
  ]
}
idrequired — must match the folder's name
namerequired — what the sidebar shows. The zip's file name is only a fallback if this is missing.
authorrequired — shown on the set's card
licencerequired — also shown on the card
descriptionoptional
name, label per iconrequired — name is lowercase with hyphens and must be unique; label is the readable one
hue per iconoptional — a #rrggbb tint

Two tiles per icon

Every icon carries the same picture at two sizes, both transparent PNG: 60×60 for the deck and 180×180 for the editor. Each one must be under 512KB.

If you'd rather not make two sizes by hand, that's fine: give one square PNG of 180 or more and the app will make both.

What the app checks

  • pack.json is there and readable
  • id matches the folder and is lowercase with hyphens
  • Icon names are unique inside the set
  • Every file the manifest names actually exists
  • Tiles are the right size, transparent, and under 512KB
  • Up to 2000 icons, 20 sets of your own
  • Archives over 25MB are refused
  • __MACOSX/ and .DS_Store are ignored

If something's missing, the whole import is refused — you never end up with half a set. And if the id clashes with General or macOS, it's imported as workshop-2 and the app says so. Shipped sets are never replaced.

Before you zip — the set checklist

  • One folder, named as the id
  • pack.json with id, name, author, licence
  • Every icon listed in icons
  • Both tiles for each icon, 60 and 180
  • Transparent PNG throughout
  • Emoji in the id, spaces, capitals
  • Duplicate icon names
  • A manifest naming files you didn't include
  • An empty licence — it's shown on the card
  • Naming it general or macos

Where it goes. On the Icons page: New set… makes an empty set of your own to start from. Add icons… takes your pictures one at a time (or a batch — drop them on the page), and they land in whichever of your sets is open. Import a set… takes a zip built to the rules above, and it becomes a set of its own with your name on the card. Export… on any set — including the ones that ship with the app — hands you that zip to keep or pass on. The sets that ship with the app stay read-only and are never overwritten.
